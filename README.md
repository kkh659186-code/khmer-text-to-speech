# Khmer Text to Speech Web App

A simple web application that converts Khmer text to speech with download as MP3 functionality.

## Features

- Input Khmer text
- Play speech directly in browser
- Download generated speech as MP3
- Modern and clean UI

## Usage

1. Clone this repository
2. Open `index.html` in a modern web browser
3. Enter Khmer text in the textarea
4. Click "ស្តាប់សំឡេង" to play
5. Click "ទាញយក MP3" to download

## Browser Support

- Chrome
- Firefox
- Edge
- Safari

Note: Some browsers may have limited Khmer voice support.
